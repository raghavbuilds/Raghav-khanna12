# Raghav Khanna — Portfolio

A responsive, static portfolio site for recruiters and engineering teams. It uses plain HTML, CSS, and JavaScript and can be hosted for free with GitHub Pages.

## Preview locally

Open `index.html` in a browser. There is no build step.

## Personalize before sharing

- Add a professional email address and LinkedIn URL in the contact section.
- Complete or remove the clearly marked experience, education, certification, and bio placeholders.
- Update `resume.txt` with verified role history, impact, contact details, education, and credentials. Remove all bracketed reminders before using it as a final résumé.
- Keep project summaries aligned with the linked source repositories.

## Hosting

The site is intended for the public repository `raghavbuilds/Raghav-khanna12` and GitHub Pages. The static files can be published from the repository root using GitHub Pages settings.
